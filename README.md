# AI-Final2
My project is an AI training program that helps users input a link to check the probability of the link being a possible phishing link. The AI learning model I chose to use for the program is PyTorch. The program treats the URL as a sequence of characters and learns which patterns (like suspicious subdomains or random strings) indicate a scam. The model is built with a standard Neural Network design using an embedded layer to break down the ASCII value of each character (0-255) and turn it into a vector value. This helps the model learn that certain characters might be related or suspicious in certain contexts. The program flattens the vectors into a long line of numbers for the next layer to read. That information is then fed into the ReLU stack that looks for patterns in the flattened data, which then outputs a number. If it's high, it thinks it's most likely phishing; if it's low, the link is most likely it's safe.
